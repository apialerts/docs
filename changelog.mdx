## 2026 — What's Coming

We're focused on making API Alerts a complete notification routing platform this year:

- **Integrations & Routers** — Route events to external destinations like Slack, Discord, and webhooks based on event name matching
- **PHP SDK** — nearing completion
- **Rust SDK update** — shipping alongside PHP
- **Team management** — workspace invitations, role-based access, and channel assignments are now live

## 2025-08-03

**Web Admin Public Preview**

We are excited to share a public preview of the new Admin Panel!

- Create and manage Workspaces, Channels, API Keys
- Update your account details
- View all recent events and filter by workspace channel
- Add a Tier 1 subscription to increase your event rate limit
- Use the Event Tester to send events to your connected devices
