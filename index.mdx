## How It Works

1. Create a workspace in the [API Alerts dashboard](https://apialerts.com/app) or mobile app
2. Generate an API key for your workspace
3. Send events using an SDK, the REST API, or an integration
4. Your team receives push notifications on their devices

Learn more about [workspaces, channels, roles, and plans](/concepts).
