## Installation

```bash
pip install apialerts-python
```

## Usage

```python
from apialerts import ApiAlerts

client = ApiAlerts('YOUR-API-KEY')

# Simple notification
client.send(message='Deployment successful')

# With all options
client.send(
    message='New user signed up',
    channel='developers',
    link='https://dashboard.example.com/users/123',
    tags=['signup', 'organic'],
)
```
