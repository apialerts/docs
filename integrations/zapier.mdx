<Note>The API Alerts Zapier integration is currently in public beta.</Note>

Connect API Alerts with thousands of apps through Zapier. Send notifications from your favorite services without writing code.

## Getting Started

1. Join the [public beta](https://zapier.com/developer/public-invite/197749/0cb074b8ee0dfaa800469c64277b193c/)
2. Create a new Zap in Zapier
3. Choose your trigger app (e.g., GitHub, Stripe, Google Sheets)
4. Select **API Alerts** as the action app
5. Configure your notification message

## Use Cases

- Get notified when new entries are added to Google Sheets
- Receive alerts for Stripe payments
- Monitor form submissions from Typeform
- Track new GitHub issues or pull requests
- Get notifications for calendar events

## Limitations

- One notification action available (more coming soon)
- Beta features may change before final release
- Limited to text-based notifications

Full documentation and additional features will be available upon official release.
