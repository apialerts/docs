Features currently planned or in development. Check back for updates.

## In Progress

- **Workspace team members** — invite users, assign roles, manage channel access
- **Webhooks** — route events to external endpoints via the router/destination system
- **Event keys & event names** — pre-defined event types for consistent routing and filtering (coming soon)
- Additional subscription tiers and custom rate limits

## Planned

- **Email destinations** — deliver event notifications to team members via email
- **SMS destinations** — deliver event notifications via text message
- **Zapier triggers** — use API Alerts events as triggers in Zapier workflows
- **Slack, Discord, and Teams** — deliver notifications directly to your team's chat channels
- Many more integration destinations and sources to make it easier than ever to connect to API Alerts
- Event image support
